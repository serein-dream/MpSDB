# 基于阿里云的函数计算和OSS存储实现的多方数据库安全计算系统

## 代码结构
Serverless版是本系统的代码内容，gRPC版是本地集群方式部署的对比系统代码

## 论文链接
本文详细描述了基于无服务器计算的多方数据库安全计算系统的设计与实现。相关论文《基于无服务器计算的多方数据库安全计算系统》可以在以下链接查看：[论文链接](https://www.jos.org.cn/jos/article/abstract/7283)

## 系统简介
本系统是基于阿里云的无服务器计算（FC）和对象存储（OSS）服务实现的多方数据库安全计算系统。通过该系统，多个数据库能够在保证数据隐私的同时共同完成计算任务。系统设计旨在提升计算的可扩展性和高可用性，支持在数据库节点掉线的情况下继续运行，并能自动伸缩以应对不同量级的请求。

## 功能特性
- 支持横向和纵向数据结构的查询任务和建模任务。
- 实现基于无服务器计算的多方数据库安全计算架构，能够在阿里云 FC 和 OceanBase 数据库上高效运行。
- 采用同态加密保证数据隐私安全。
- 动态资源伸缩，优化计算成本与系统性能。
- 可容忍数据库节点掉线，确保高可用性。

## 实验与性能评估
通过大量实验，我们验证了系统在低频查询、横向建模等任务上的优势，最高可节省 78% 的计算成本，并且性能提升 1.6 倍。系统在支持复杂查询和纵向建模等任务时也展示了较强的能力。
